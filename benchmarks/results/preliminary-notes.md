# Preliminary benchmark files

The files named `*-before-copy-removal.csv`, `*-after-coalesce-run*.csv`, and `*-run1.csv` are early exploratory runs. They used an image-backed static child buffer, an earlier harness, and an older p95 calculation, so they are not the apples-to-apples evidence for the final change. Use the `*-private-rw-*` files, the current competitor file, and the two `history-*` files for comparisons described in `summary.md`.
